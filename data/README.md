# 数据资料

## 视频

`raw/` 中的两个 AVI 文件来自微信转存。仓库中的英文文件名用于跨平台引用，原始文件名和视频属性记录在 `raw/MANIFEST.md`。

- `raw/calibration_video.avi`：原文件名以 `07` 结尾的标定视频。
- `raw/marker_video.avi`：原文件名以 `54` 结尾的校内赛标志物测试视频。

两段视频均为 1440×1080，帧率约 70.4 FPS。请以实际读取到的容器元数据为准，不要在代码中硬编码帧率。

## 相机参数

`camera/capture_settings.yaml` 记录了截图中可确认的采集设置：曝光时间显示为 `10000.0000`、增益为 `16.0114`、宽度为 `1440`、高度为 `1080`。截图没有标注曝光时间单位，也没有提供相机内参、畸变系数或标志物实际尺寸。

因此，必做识别不依赖内参。需要进行位姿估计时，请在报告中说明内参和畸变系数的测量或标定来源。

## 标志物尺寸参考

[科技核心 MARK 灯尺寸示意图](../src/tushenghao/docs/assets/marker_dimensions.jpg)提供标志物外观、尺寸标注和局部细节。进行位姿估计时，请确认尺寸单位，并使所选图像关键点与模型中的三维点一一对应。
