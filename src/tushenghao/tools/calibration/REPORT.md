# 相机标定报告

## 标定板

- 类型：7x7 对称圆点阵（circles grid）
- 圆心间距：0.03m
- 来源：PNX 27 算法组培训群（乔小龙确认）
- 检测函数：`cv::findCirclesGrid` + `CALIB_CB_SYMMETRIC_GRID`

## 输入数据

- 视频：`data/raw/calibration_video.avi`
- 分辨率：1440x1080
- 总帧数：6966

## 帧选择

- 手动挑选：52 帧（`scripts/frame_picker.py`）
- 检测成功：49 帧（3 帧 `findCirclesGrid` 未检出，自动跳过）
- 选帧标准：49 圆点全可见、清晰无运动模糊、角度/位置/距离尽量散开
- 帧号列表：见 `docs/evidence/frames_2026-10-11.txt`

## 标定结果（2026-10-11，误差口径修正于 2026-10-12）

- 图像尺寸：1440 x 1080
- 重投影误差：**0.095px**（验收标准 < 0.5px 为优秀；注：2026-10-12 修正统计口径，旧值 0.013px 作废）
- 输出文件：`src/tushenghao/config/calibration.yaml`

### 内参矩阵 K

```
fx = 2394.37, fy = 2394.81
cx = 705.00,  cy = 565.41
```

主点接近图像中心（720, 540），fx/fy 基本一致，符合预期。

### 畸变系数（k1, k2, p1, p2, k3）

```
k1 = -0.0642, k2 = 0.2239, p1 = -0.0004, p2 = -0.0010, k3 = 0.6820
```

径向畸变为主，切向畸变很小。

## 方法

1. `findCirclesGrid` 检测每帧的 49 个圆心（2D 像素坐标）
2. 按板参数生成对应的 3D 世界坐标（z=0 平面，单位米）
3. `cv::calibrateCamera` 非线性优化求解 K 和畸变
4. `cv::projectPoints` 重投影计算 RMSE（平方误差求和/总点数后开根号；另用 `calibrateCamera` 返回值交叉核对一致）

2D-3D 对应靠行优先顺序一致保证（检测返回顺序与生成顺序一致）。

## 验收对照

| 验收项 | 要求 | 实际 |

| 标定板规格 | 7x7 圆点 / 0.03m | ✅ |
| 检测函数 | findCirclesGrid | ✅ |
| 训练帧数 | 20-30 帧 | 49 帧（超量，无害） |
| 重投影 RMSE | < 0.5px 优秀 | ✅ 0.095px |

## 已知限制

- 仅针对本相机、本次采集条件标定；换相机或镜头需重标
- 独立验证未做（原"无过拟合风险"判断已撤回：视角覆盖不足、板面不平、圆心系统偏差都可使训练拟合好而外部测量差；计划用一次独立采集会话重标定做交叉验证，同录像相邻帧不算独立验证）
- 尺度依赖圆心距 0.03m 的准确性；RMSE 只验证像素拟合，不验证绝对尺度
