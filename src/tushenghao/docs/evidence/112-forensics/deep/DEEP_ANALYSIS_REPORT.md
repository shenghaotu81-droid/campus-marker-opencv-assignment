# 112 帧漏检：深入取证、反事实验证及修复路线修订

## 结论与证明边界

**已证实：问题主要位于原图角点取证，不是本集合中的三 L 几何生成、M/S 补全或显示层。它包含候选搜索不完备、逐像素位置门控和原始栅格边界误差模型不匹配三类问题；不能用一个原因解释全部 112 帧。**

最强的工程证据是一个保持全部生产质量阈值的独立补查原型：完整处理同一视频 1676 帧，检测从 976 增至 996，新增 20 帧全部属于指定集合，原 976 帧没有丢失，原始 Detection 四角坐标逐值不变。这个原型运行了原生产几何、四角解析、证据验证、语义和 float 发布链，没有用显示历史或预测点填框。它没有修改仓库生产代码，仍不是生产实现。

对剩余问题，已确定残差门控的直接作用及扫描行周期结构，已用留出行验证排除“只是多拟合一个参数”的简单解释。**本轮没有证明周期模型已经恢复剩余检测，也没有独立亚像素角点真值，因而不能声称 112/112 修好、零误检、全部定位误差小于 2 px，或把视频采集/编码硬件确定为根因。**这些结论边界是可复核数据本身的限制，不以模糊的“可能全能恢复”代替。

本报告取代第一轮报告中的修复优先级；第一轮统计作为历史记录保留。

## 根因链条与反证

### 1. 端点离散化造成真实候选漏搜：已由固定门限整链反事实证明

`lib/corners/corner_edge_fit.cpp::fitObservedEdgePair` 虽然枚举了简化端点之间的全部连续区间，却只在简化端点的既有 2 px 转折剔除距离附近补充端点。这不等于枚举了真实轮廓上所有连续支持。

独立原型扩展为全部真实轮廓索引作候选端点，质量约束仍为原值，支持依然是原轮廓上的连续区间，没有丢掉区间内部的不利像素。取证端点去重采用**完整有序支持像素序列**，并非只按两端坐标去重；后者在轮廓回走时会错误合并不同路径。本轮所有 116 次端点试验采用完整支持去重版。

端点补查产生 20 次原本没有的合格角，说明一部分旧失败不是“原图根本缺边”，而是候选表示不完备。整链中其中 19 帧恢复；帧 369 的 P1 局部恢复后，P2 仍失败，因此不能把 20 个局部输出都算成 20 个检测。再加位置谓词恢复帧 784，整链合计 20 帧。

这也是反证：把扫描范围扩大为所有真实端点仍只恢复有限样本。其余角不能归咎于端点索引单一缺陷；更不能继续无限加端点寄希望于覆盖全部。

### 2. 位置判断混合了线段定位与单像素粗糙度：帧 784 已证实

帧 784 的 M1 原图支持唯一，指定模型顶边与右边投影见 `frame784_position_values.json`。正确右外边的一段 37 点连续支持，原逐点有限段距离最大约 **9.009298 px**，超过 9.0；其平均拟合残差 **0.452565 px**，原本满足 0.5。

将位置门控推迟到拟合后，检查支持像素在拟合线上的投影到有限模型边的最大距离，同样使用 9.0 门限，独立双精度 TLS 复算最大约 **8.069556 px**。实际整链原型仍使用原 cv::fitLine，不以独立 TLS 复算值冒充同一浮点结果。原生产 validator 和 float 发布均通过，帧 784 输出四个当前原图实测角。

因此本例不是拟合残差、支持跨度或连接长度不合格；是逐点硬位置判据在拟合前把合格外边删掉了。仅把 9.0 改成 9.01 不是本报告的方案。拟合后位置谓词必须继续关联指定有限边，不能像“移除位置门控”试验那样不加区分放行内侧平行边；移除位置的局部输出数 42，不能冒称后验位置方案恢复 42 帧。

### 3. 单一直线的原始链码平均残差，是本集合的主要直接阻断；误差模型遗漏扫描行结构

111/112 帧的失败角在移除平均残差门控后可形成候选；其余拟合流程仍执行。所选边的平均残差多在 0.5 附近，不是几十像素的形状错误。它们来自二值化后 CHAIN_APPROX_NONE 的串行轮廓，包含真实像素回走和奇偶行边界偏移。对同一组真实像素，按行留出验证的周期模型明显优于单一直线，支持“当前单线残差混合了定位趋势与空间周期扰动”的判断。

这个结论不同于“那些像素必须删除”或“把 L2 换鲁棒拟合就好了”。数据反证包括：双精度 TLS 恢复 0；唯一像素等权仅恢复 4；外包络恢复 0；普通灰度亚像素精化只在 41 对固定支持上通过局部条件。不能把这些方式列为已解决主因的方案。

视频本地元数据为 H.264、yuv420p、1440×1080、1676 帧、field_order=progressive。观察到两行周期不能据此认定隔行扫描、摄像头硬件或某个编解码步骤损坏。本轮确立的是**输入边界的空间结构和检测器的误差模型不一致**，不是确定其在采集链中的起源。

平均残差与角点定位误差是不同量：本轮没有角点真值，不能拿较低模型残差直接证明角点更准，也不能拿视觉上是目标直接证明原 0.5 门限理应允许。工程缺陷的修复对象应是候选完备性和观测/验证契约；新的观测模型必须能独立重算原始来源、结构扰动及角点不确定度。

### 4. 帧 382 是同一物理绑定的两个锚点表示，不是两套不同语义身份：身份关系已证实

`frame382_competition.json` 保存两父完整证据。两者六片绑定完全一致：L0→5、L2→0、L3→1、M1→3、S1a→4、S1b→2；仅一个三 L 凹点选取及仿射不同。父 0 产生完整角点测量，父 1 在 P2 失败；生产以 `UNRESOLVED_COMPETING_GEOMETRY` 阻断已有测量。

父 0 验证残差 1.609729，父 1 为 1.537959。因此按父残差挑最优反而会挑失败分支，不能用排名绕开竞争。

已证明的是“同一来源/绑定存在多个估计表示”；尚未在原型实现“同一绑定下所有候选搜索域的联合枚举及唯一性证明”，不能直接删除失败父或宣布帧 382 可安全发布。修复应在物理绑定等价类上聚合搜索域，保留同一来源下不同几何测量的歧义检查，而不是让估计器种子数决定语义竞争数。

## 修订后的四条结构性路线

### A. 首先修复失败角的连续支持候选补查（已验证 19 帧贡献）

**改动位置：** `fitObservedEdgePair` 的端点生成、连续支持去重和弧对枚举；原成功取证原样返回，失败时才补查真实端点。

**依据：** 不改任一质量阈值，仍找到原算法未搜到、被原生产 validator/发布接受的真实连续支持；端点搜索缺陷已具整链证据。

**预期：** 本视频验证贡献 19/112（16.9643%）；同帧后续角仍须验证，不根据单角 success 夸大。与 B 合计 20/112。

**成本和风险：** 全端点 n(n−1) 区间及合格弧二次配对只是取证参照，不建议原样全量放进生产。生产需连续支持索引缓存、完整支持等价去重、拓扑邻接缩减以及明确资源耗尽/截断状态；不能将达到资源上限伪装成“没有几何解”。优化必须逐帧对照本轮参照，证明未漏掉合格解。新增短支持仍应满足原 10 个唯一点、14 px 跨度和原连接/延伸预算；用被选支持检查有无因支持变短而放大交点不确定度。

### B. 将有限模型边的位置判定移到观测拟合之后（已验证 1 帧贡献）

**改动位置：** `fitObservedEdgePair` 的早期 position_mask 与 `matches`。区分连续支持的实测粗糙度和实测线段对模型的有限段定位；保留同一 9.0 门限、方向门控和真实凸转折。

**依据：** 帧 784 的 9.009298 对 8.069556 以及完整 validator 通过，直接说明早期逐像素谓词的职责问题。

**预期：** 本集合实际恢复 1/112（0.8929%）。本方案的全量检出和语义误关联风险应单独评审，不能把“完全移除位置门控”的 41 帧覆盖算进预期。

**成本和风险：** 将门控推迟会拟合更多无关弧；本轮 positionfit 原型即使输出基本不变也有额外成本。需要保守的必要条件预筛，证明不会提前排除后验合格弧；拟合线误关联内侧边的风险需独立负样本检查。本轮没有可比的生产性能验收，插桩耗时不能当作性能收益。

### C. 主路线：明确原始像素来源、结构扰动与物理外边的观测模型

**改动位置：** `fitArc` / 原图观测层、内部 `CornerEvidence` 及 `validateCornerEvidence` 的计算契约；公共 Detection 和公开接口不变。

**依据：** 单线原始平均残差主导 111 帧；扫描行周期模型在留出行上改善 107/115 条问题边。像素串行权重、灰度精化或更高数值精度分别不足以解释/修复整体。

**具体设计：** 保留原始有序连续支持与行坐标，分开记录物理线参数和可辨识的空间扰动参数。例如近竖直边采用 `x=a(y-y0)+b+c(-1)^y`，所有原支持像素均参与；物理定位使用公共趋势项，并在验证器独立重算扰动、残差和参数不确定度。模型启用必须经过按扫描行留出的一致性检验，禁止单纯增加参数让任意弧达标。对没有稳定周期结构的弧保留严格拒绝，不以一个数据集的周期模型替代所有观测。观测角必须仍由两条当前真实边求交，不能用父仿射代替。

**预期：** 固定支持试验中 98/115 对模型残差达标，是观测模型覆盖证据，**不是可承诺恢复 98 帧**。不同方案覆盖重叠，剩余 92 帧的完整角、来源唯一性、有限支持和发布需随新观测契约一起验证。本轮不承诺未经整链实现的恢复比例。

**成本和风险：** 中到大规模内部建模/证据验证改动。不得把周期模型残差写进现有“原像素到直线平均垂距”字段却让字段仍宣称旧含义；不能让旧 validator 错把改过的证据当原始单线证据。新内部证据必须保存原始来源、估计过程、模型残差和真实定位误差含义，给单线/周期模型建立显式一致性契约。需要带定位真值的合成栅格/周期扰动样本及独立实拍验证，控制同一来源多模型的几何冲突与选择偏差。测试应针对模型可辨识性和定位误差，不能只镜像实现。

### D. 最后修复同一物理绑定下的父估计竞争传播

**改动位置：** `decodeStage` 的 unresolved 传播，几何补全后的物理绑定分组，以及 `resolveObservedCorners` 的联合搜索入口。

**依据：** 帧 382 六片身份完全一致，父表示不同；现逻辑把局部估计失败当成无法排除的独立语义竞争。

**预期：** 针对当前唯一记录的潜在额外范围 0–1/112；当前不宣称已安全恢复。这个数字不与 C 的支持弧统计相加。

**成本和风险：** 中规模内部改动，需要在同一物理来源/绑定等价类内联合搜索并保留所有观测解，对不同绑定及真实多几何解继续保守拒绝。仅按 component 集合（忽略标签）、只挑最低残差父、直接删除失败父均不可作为实现。若联合域仍存在互相冲突的合格角，必须拒绝。

建议实施顺序为 A+B 的可验证局部修复→C 的明确观测模型契约→D 的来源等价类处理。纯阈值放宽、历史填框和撤回的 0.75/9.5 组合均排除。
