# 112 帧沙盒攻关：实施方案、证据与性能验收

## 1. 推荐与结果

推荐 **保持原成功路径 + A/B 失败补查 + C1 局部三参数周期模型 + 精确等价性能优化**。不要采用朴素全端点版本，不要采用单一全帧奇偶偏移 C2，不需要为帧 382 修改竞争规则。

本方案已在当前分支真正实现，运行公共 `Detector::process` 的完整视频链；不是根据局部残差推算检测数。全部 1676 帧从 **976 个检测变成 1088 个检测，指定 112 帧全部恢复**。原成功帧没有损失，原成功帧的 raw 四角浮点坐标逐值不变，指定集合之外没有新增检测。两个最终重复运行的全部 raw 输出一致。新增检测可能改变后续 temporal 历史，因此不声称平滑输出不变。

最终顺序复测、长尾、独立真值测试和函数 profiling 的具体值见第 4、5 节及 `summary.json`。核心范围已完成验证，不把下一步生产实施所需的验收步骤冒充本轮尚未完成的实验。

**证明范围：** 112/112 是这个固定视频集合的完整检测恢复结论；合成定位验收是已知真值条件下的原图角解析/验证结论，不代表任意相机或任意场景的误检率。全视频中没有集合外新增检测，可以证明本视频没有额外接受集合，不能据此声称全场景零误检。原视频没有独立亚像素标注，不能用模型残差或叠图冒称实拍定位误差小于 2 px。采集硬件/编码器的具体起因不在现有视频可辨识范围内；检测器的直接失败机制已经由冻结输入反事实和实际修复确定，不依赖该起因。

## 2. 根因链条：三类缺陷，不是单一阈值问题

### 2.1 候选端点搜索不完备：A

`lib/corners/corner_edge_fit.cpp::fitObservedEdgePair` 原算法只枚举简化端点及其既有 2 px 转折修剪邻域之间的连续弧。真实轮廓的所有像素虽然在输入里，但候选端点没有覆盖全部支持。这使某些满足原质量约束的连续弧根本没有进入拟合。

保持所有门限，失败后用全部真实轮廓索引补查：冻结的 116 次失败角输入产生 20 个局部输出，但帧 369 还有另一个角失败，因此独立整链 A 的收益是 **19 帧**，不能把局部 20 个角计成 20 个检测。完整有序支持序列用于去重，不能只用两端点坐标：CHAIN_APPROX_NONE 可以回走，相同坐标端点不等于同一路径。

### 2.2 像素粗糙度与物理边定位混入同一个前置谓词：B

帧 784 的正确右外边，原像素对指定有限模型边的最大距离为 9.009298 px，略超过原 9.0。相同支持的平均拟合残差约 0.452565，符合原 0.5；投影到拟合线后，对有限模型边的最大距离约 8.069556。后一个数是前轮独立双精度复算，非本轮 cv::fitLine 的逐位值。

失败补查时，把有限段位置检查改为拟合后实测支持投影的位置检查，仍用 9.0，仍检查指定外边和方向。实际整链恢复 **帧 784 一个检测**。这不是删除位置门控，也不是将 9.0 改成 9.01，更不是用父仿射角填框。

### 2.3 数据具有两行结构，单线残差模型遗漏该结构：C

冻结输入上仅移除平均残差门控，115/116 次失败角形成候选，覆盖 111 帧；所选边最大平均残差 P50 为 0.528398、P95 为 0.588185、最大为 0.603756 px。双精度 TLS 恢复 0，唯一像素等权恢复 4，外侧扫描线包络恢复 0；单纯数值精度、去重或继续扩端点不能解释主要问题。

按不重叠行块留出验证，周期模型在 107/115 条问题边的留出误差上优于单线，中位数 0.535834→0.417995；同参数量随机行标签的 100 次对照中，101/115 条真实奇偶标签取得经验下尾概率 ≤0.05。这是空间结构证据，不是经过独立性/多重比较校正的总体显著性结论。

本轮把模型真正接入四角、validator、语义、float 发布和公共 process。C1 OLS 恢复总计 106/112；使用与绝对残差门控一致的相位中位截距后恢复 111/112；最后消去相位截距、对斜率进行 L1 目标精化后恢复剩余帧 153，达到 112/112。这些是不同完整版本的总恢复数，不能相加。

帧 153 最终 P2 使用垂直物理线 x=1135.5、水平物理线 y=517；垂直周期 c=0.5，原始平均残差 0.791667、模型校正平均残差 0.416667，完整支持见 `selected-evidence.jsonl`。这明确展示新旧误差量不同，不能声称新支持的旧残差也满足 0.5。

帧 153 不需要新视觉阈值：OLS/固定 OLS 斜率的中位截距并不最小化整条弧的平均绝对残差。最后一层精化的是同一个 a/b/c 模型的估计目标，不增加参数、不删异常点、不增加局部曲线自由度。实现保存全部连续支持，包括回走重复像素；这些像素仍按原串行权重参与计算。

### 2.4 帧 382 的 D 路线已经被直接验证替代

前轮证明其两个三 L 父表示绑定完全相同，L0→5、L2→0、L3→1、M1→3、S1a→4、S1b→2；父残差较小的那个恰好角点失败，不能以排名绕过竞争。本轮 C1 相位中位版本让原失败父也生成合格完整观测，原竞争、语义和发布逻辑自然通过，帧 382 已恢复。

因此本视频不需要修改 `unresolved` 传播，不删除失败竞争，不人为挑父，不引入绑定等价类聚合。D 的通用设计仍可作为其他数据的独立项目，但在这次完整修复中没有必要，不能为了“路线齐全”增添未经收益证明的生产改动。

前轮完整原始依据见 `../112-forensics/deep/DEEP_ANALYSIS_REPORT.md`，本报告的实际沙盒结果取代其中“周期模型尚未接入整链”的历史限制；历史报告不重写，保证实验顺序可追溯。

## 3. main 上逐文件实施方案

本节是给**新 main 工作区**的设计说明，不要求运行历史 `/tmp` 脚本，不要求 cherry-pick 本沙盒，也不要求复制环境变量或临时全局状态。当前分支绝不合入 main。本轮没有操作 main。

### 第一步：帧内原图观测索引

修改 `lib/corners/corner_observation.hpp/.cpp`，新增内部 `OriginalContourIndex`：持有当前帧原图分割轮廓、是否已准备、component 映射结果缓存；在 `lib/pipeline/decode_stage.cpp::decodeStage` 内创建，由 `corner_resolver.hpp/.cpp` 内部入口显式传递。灰度、阈值、完整原图 findContours 每帧最多一次；同一个工作图 component 的双向边界关联每帧最多一次。准备应惰性发生，无待解析假设时不分割原图。

缓存生命周期限定一次 decode；图像、阈值、工作图几何映射和预算在此范围必须不可变。key 使用 component ID，不能跨帧复用，也不能把同 ID 的新 contour 当同来源。保留原内部 wrapper：独立调用使用新 index，以免 fixture 修改图像/预算后读到旧缓存。正式接口以 const 数据和 frame ID 明示来源，不使用地址相等作为帧身份。

隔离确认已完成：关闭 A/B/C、仅保留优化的最终库完整运行 1676 帧，与原库的 status/raw 四角差异为 0（`optimized-baseline-correctness.jsonl`）。该运行与独立测试并行，计时不用于性能结论。

原因是原四角/多父重复处理相同 1440×1080 原图。它与算法正确性无关，必须先用原路径确认 976 帧/角点全等。

### 第二步：弧对搜索的精确等价优化

修改 `corner_edge_fit.cpp::fitObservedEdgePair` 内部：

1. 预计算轮廓上每个像素的两个有限边位置 mask；在构造前置位置模式的连续弧时做 AND，归零即拒绝。拟合后位置模式不能使用该早期拒绝。
2. 缓存每个像素坐标的首次轮廓索引，保留原 `find` 的“首次”语义；缓存连续弧的真实起止来源索引。
3. 构造循环弧长前缀表。连接长度明显超预算时先拒绝；必须给浮点前缀差预留保守舍入界，近预算者仍执行原逐段局部求和。沙盒界为 `64*epsilon*N*max(1,totalLength)`，这是数值一致性缓冲，不是放宽视觉预算。
4. 拟合残差循环顺便记录支持 AABB；AABB 无交集时无需构造/查询共享像素集合。有交集继续原精确支持互斥检查。
5. 弧对的全部质量谓词通过之后，仍对**所有候选**执行几何歧义检查；即使候选评分较差也不能提前跳过歧义。只有歧义通过并优于当前最佳/原 tie-break 后，才深拷贝两条支持和转折弧到 evidence。评分、比较顺序及 tie-break 保持原样。

这一步不改支持、门限、枚举覆盖或成功取证选择。不要用“取最近两个无限线”替代真正凸连接弧。判据失败计数可能因提前执行等价必要条件而重新分类，因此回归比较输出与原始来源，不能要求所有拒绝计数相同。

### 第三步：A/B 失败补查

保留旧候选/位置模式成功直接返回。失败时依次：旧端点+后验有限段位置；全部真实端点+原位置模式。每个候选仍是原轮廓的连续有序区间，仍保留全部内部像素。全端点阶段按完整有序支持去重，严禁按端点坐标、拟合参数或 unordered 支持集合去重。

`matches` 后验位置计算：把每个实测支持 p 投影到实测物理拟合线，计算投影点对**指定有限模型边**的距离；最大值须仍 ≤9.0。原方向、跨度、唯一点数、转折、延伸、交角、几何歧义和原图来源门控保留。

先验约束用于关联来源和有限边，而非制造观测。保留 A/B 完整 reference，即使以后加索引，也必须与该 reference 比较全部候选及最终输出，不能用未经证明的端点截断只追求快。

收益验收必须到整链：976→996、目标新增 20、原成功输出全等、集合外新增 0。朴素版本变慢约 27%，不能单独交付；必须与前两步性能优化一起评审。

### 第四步：C1 模型与估计器

在内部原图弧拟合层建立明确模型类型，近竖直采用 `x=a(y-y0)+b+c*h(y)`，近水平对称采用 `y=a(x-x0)+b+c*h(x)`；h 为整数扫描坐标奇偶的 ±1，沙盒约定奇数 +1、偶数 −1（与常写的 `(-1)^y` 差一个系数符号，模型集合相同）。物理直线只取 a/b 的趋势项，c 解释周期结构；最终角由两条物理直线相交得到。

a/b/c OLS 使用中心化充分统计量 tt/hh/th/tz/hz 的闭式 2×2 解，不对每条弧构造通用矩阵。对全部串行点计算 mt/mz/mh，令 T=t−mt、Z=z−mz、H=h−mh；`tt=sum(T²), hh=sum(H²), th=sum(TH), tz=sum(TZ), hz=sum(HZ)`，`D=tt*hh−th²`；`a=(tz*hh−hz*th)/D`、`c=(hz*tt−tz*th)/D`、趋势截距 `b=mz−c*mh`，线原点是 `(b,mt)` 或其水平对称形式。方向 `(a,1)` / `(1,a)` 单位化；校正残差分别为 `|x−a(y−mt)−b−c*h|/sqrt(1+a²)` / 水平对称式。必须检查两相位都有样本、正规方程满秩和所有参数有限；机器精度相关秩条件不当作视觉宽容门限。

固定 OLS 斜率时，各相位 `z-a(t-t0)` 的中位数分别为 beta−、beta+，取 `b=(beta−+beta+)/2`、`c=(beta+−beta−)/2`。偶数样本中位数采用中间两值平均。这与原平均绝对残差门控一致，比以平方目标拟合后再用绝对目标拒绝更合适。

只有原拟合及 A/B、相位中位模型仍失败时，精化同一模型斜率。对固定 a 消去两相位截距后，`F(a)=sum |z-a(t-t0)-beta_phase(a)|` 是凸的坐标 L1 目标；它不是任意曲线拟合，也不声称是角点真值误差的最小值。目标求值复用两相位 scratch 向量；固定 40 次凸区间搜索后，复算原 OLS 斜率、零斜率和最终小区间内所有同相位整数点对定义的斜率拐点。相同拐点只计算一次，保持首次枚举顺序，避免等目标改变选择顺序。

可用严格证明的快速证书：按每个扫描坐标分组，计算各组最小 L1 损失之和，它是任何 a/b/c 模型的全局下界；零斜率恰好达到该下界时直接返回零斜率或同目标的原斜率。沙盒只用严格相等判定，不以近似比较放宽 0.5 门控。这只证明该支持的坐标 L1 最优，不证明该支持属于目标。

斜率区间取 `[-max(1,zmax−zmin), +max(1,zmax−zmin)]`。原因是这个凸分段线性目标的有限拐点来自同相位点残差排序交换，斜率为 Δz/Δt；整数扫描坐标同相位的非零 Δt 至少为 2，所以所有有限拐点都在该区间内。固定支持若目标处处平坦，区间内亦有最优值。每次三分比较 `(2lo+hi)/3` 与 `(lo+2hi)/3` 的损失，40 次后区间宽度为初始宽度乘 `(2/3)^40`；同目标、同斜率候选保持原优先顺序，不将比较容差变成视觉门限。

斜率搜索区间与有限迭代是数值算法的一部分；正式实现必须保留本轮 reference 并校验拟合系数、残差与发布输出。不准把达到资源上限当“没有解”。当前实现没有声称无限精度全局搜索，也不能把 40 次精化的收益外推成所有输入的唯一最优物理线。

沙盒具体失败路由为旧路径→B→A→C1 原端点原位置→C1 原端点后验位置→C1 全端点原位置→L1 精化同样三个阶段。实施时把路由封装在实例内策略，不使用 `MARK_SANDBOX_*` 环境变量。旧成功立即返回，因此本视频原成功 raw 输出不变。

### 第五步：独立证据契约及 validator

修改内部 `lib/corners/corner_types.hpp::CornerEvidence`、`corner_evidence_validation.cpp::validateCornerEvidence`，增加模型类型、轴、c、校正平均/最大残差等**内部**元数据。原 `line_mean_residual_px_`、`line_max_residual_px_` 仍是所有原始像素对物理直线的真实垂距；`error_` 仍保留旧定义用于排序。不能把校正误差偷偷写进旧字段。

validator 必须从完整原始有序支持重算两类残差、重建估计器参数与物理线、检查交点在线、支持来源与连续性、独立支持、跨度、延伸、转折及 frame ID。模型平均垂距的 0.5 门控见第 6 节。不同模型类型明确区分，不能只凭调用方声明的低误差接受。

沙盒用同一个纯拟合 helper 做 validator 的可重复参数重建，另有独立真值/篡改试验来避免“自我重算成功就是正确”的循环。正式 helper 应采用显式 immutable 输入和局部 scratch，不用 thread_local 保存证据上下文。本轮 C1 本身不需要全帧系数；`frame_shift` 仅为 C2 对照试验，不进入推荐 main 方案。

不要更改 `include/mark/*` 或公开 `Detection`。模型类型属于内部观测证据，公众仍收到原始四角和现有字段；不要让 UI 展示实验开关或插桩细节。

C2 的实现确实每帧只估计一个全局水平奇偶位移：在原图轮廓上用固定 48 点窗口、24 点步长、近竖直且跨度至少 14 的支持估计系数，中位数得到 frame coefficient。每条弧使用同一个系数校正 x，再调用原廉价 `cv::fitLine`，没有暗中做各失败弧的局部偏移。此窗口是对照估计器定义，不是调低定位质量门限。

C2 校正是从原始证据坐标建立拟合视图，原始轮廓仍用于 component 来源关联、连接弧连续性和 raw 残差，防止统一校正破坏 CHAIN_APPROX_NONE 原来源。沙盒在 `fitArc` 内形成校正支持向量，而非重写 source contour；这个延迟形成视图与入口对所有轮廓统一施加同一坐标变换在拟合上等价，计时包含了视图形成成本。正式若采用 C2，可将完整变换视图缓存在帧入口，但不应替换原始 evidence。

C2 恢复 98/112，C1 OLS 已恢复 106/112，最终 C1 恢复 112/112。全帧共同平移的自由度不足以同时描述同帧不同边的局部周期项；不因 C2 看起来“每帧只拟合一次”就假定更正确或更快。其完整路径仍包含原失败搜索、fallback、拟合和配对，实际总耗时没有取得优势。C1 闭式 OLS/两相位中位数成本小于完整支持搜索与配对成本；L1 精化仅用作最后失败补查。

**选择 C1 的依据**是实际更完整恢复、既有回归全等、独立局部扰动实验与完整性能，而不是“参数多更好”。未选择 C2 不等于否定其他数据里真正一致的全帧扫描偏移；在本视频上它达不到本任务收益要求。

## 5. 性能：测量范围、热点和 30 FPS

环境为 Intel Core i9-14900HX，WSL/Microsoft hypervisor，OpenCV 4.6.0，CMake Release `-O3 -DNDEBUG`；`cv::setNumThreads(1)`。输入为同一 1440×1080、1676 帧视频及同一 verification YAML。公共 `Detector::process` 外部 steady_clock 包含 preprocess、detect、decode、stabilize 和诊断 Summary，VideoCapture 解码、JSON stdout 序列化、GUI/视频导出不在该计时范围。因此不能把倒数 FPS 当整机摄像/显示能力。

早期版本用于探索，期间有构建等其他任务，不以其小幅差异当精密估计。最终基线/修复版/修复版重复/profiling 按顺序运行，未与编译或其他视频/拟合实验并发；没有剔除慢帧，也没有偷偷只测成功帧。首次启动和实际失败 fallback 全部保留。WSL 下没有锁 CPU 核心/频率，结果是本机观测而非所有硬件 SLA。

## 6. 门限定义变更的独立论证

本轮未更改任何 YAML 质量阈值：平均残差 0.5、有限边位置 9.0、其他点数/跨度/方向/连接/延伸/交角等保持原值，历史撤回的 0.75/9.5 组合没有复活。但必须明确：周期模型约束的是 `|signed_raw_distance-normal_phase_coefficient*h|` 的平均值，**含义发生了变化**，不是继续用同一数字便自动证明同一契约。

独立量化来源为整数栅格坐标的最近格点量化：一个正交坐标的理想量化误差 ≤0.5，投影到斜率 a 的物理线法线时 ≤`0.5/sqrt(1+a²)`。在已经正确表达独立奇偶位移的理想模型下，0.5 是保守的量化上界，而不是从 112 帧残差最大值反推的覆盖阈值。真实轮廓回走、压缩/阈值等还会产生其他误差，所以该推导是新量的量纲/预算依据，**不证明任意真实像素必然满足**，也不证明新增参数无误检风险。

因此配合与视频完全无关的已知真值试验：固定独立种子 112 的 25 个校准样本和种子 7919 的 88 个测试样本；幅度 0/1/2 px、随机平移、旋转 −6°到+6°、全局同向/局部反向奇偶扰动。测试集含 68 个正样本和 20 个缺失支持负样本。校准阶段发现 2 px 跨行跳变的宽链码支持会触发极昂贵的穷举；因此在首次运行测试分区之前固定收敛采样：0/1 px 正样本全部保留，每个分区仅保留固定 ID 2 的 2 px 压力样本；负样本使用 0/1 px 扰动，防止先被高噪声拒绝掩盖缺角检测。被停止的初版校准完整行单独归档，未伪装成完成了原 36/120 大矩阵。这个范围调整不改变算法或门限，也未按测试结果选择样本。模型/门限没有根据测试结果调整，保留拒绝与定位误差，不仅保留通过项。已有图纸/仿射只在测试侧提供身份及真值，正式算法不读取真值。

测试的是原图四角解析和生产 geometry validator：工作图绑定作为已知输入用于隔离本次缺陷，不声称该试验同时验收上游三 L 生成的召回率。合成角真值采用未扰动图纸的连续变换，render 有像素取整，误差包含该栅格化影响；不以更靠近检测结果的“人工修正真值”消除它。

| 独立版本 | 正样本通过/总数 | 通过样本最大四角误差 px | 负样本错误接受/总数 | 参数篡改漏拒绝 |
|---|---:|---:|---:|---:|
| C1 校准 | 24/25 | 1.497220 | 0/0 | 0 |
| 原模型测试 | 42/68 | 0.887588 | 0/20 | 0 |
| C2 测试 | 52/68 | 1.224359 | 0/20 | 0 |
| C1 最终测试 | 67/68 | 1.401158 | 0/20 | 0 |

C1 校准仅拒绝 ID 2 的 2 px 压力案例；最终测试也仅拒绝独立 ID 2 压力案例，全部 67 个 0/1 px 正样本通过，所有通过样本误差 ≤2 px。C2 在测试集的全局 1 px 样本通过 14/17，局部反向 1 px 样本通过 4/16；原模型分别为 4/17、4/16。由此可区分结构表示不足与本 C2 估计器本身的损失，不能推论任意更好全局估计器也一定只有 98 帧收益。

独立理想矩形的额外链码实验 `independent-chain-budget.jsonl` 验证了压力拒绝的机制：位移幅度 0/1/2 px 的完整竖直支持最小模型平均残差分别为 0、0.253165、0.754717；按扫描行分组的 L1 下界取得同样值。2 px 位移会生成较宽的水平连接像素，单个行相位参数不能消去这些同行内距离；对该固定支持，即使斜率允许在竖直方向 ±3° 内变化，下界投影仍大于 0.5。不能为了通过压力样本把门限放宽，也不声称其他短支持必然具有同一下界。

全部 112 恢复帧的 7 张联系表已经目视核对，角点均位于目标外角区域，未见选择内片/空背景；这是定性检查，不是实拍亚像素真值。

最终独立测试中有 25 个实际使用周期 evidence 的成功样本，全部执行系数篡改并被拒绝；未用周期模型的样本不算作执行过此检查。参数篡改试验将实际用到的 c 增加 0.25，要求 validator 拒绝不一致证据；这验证证据契约，不是精度替代品。负样本的缺角半径为固定 15 px，另含全黑原图；没有按照当前失败帧外形制造专门负例。所有原始行在 `independent-*.jsonl`。

## 7. 实施顺序与逐步验收

1. 从新 main 建立原始 Reference，固定视频 SHA256、配置、OpenCV/编译器、线程数、计时范围和 112 ID；先完成其构建/现有测试及全视频 976 基线。不要从已经修改的沙盒编译“基线”。本轮基线二进制静态链接原未修改库，有独立文件 hash。
2. 只实施帧内索引及精确等价性能优化；原全部成功/失败状态与 raw 四角不变，确认缓存改图/跨帧不污染。性能改善后再增加搜索。
3. 加 A/B，完整验收 996、目标新增 20、原损失 0、旧 raw 变化 0、集合外新增 0；现有多来源/截断/歧义测试必须通过。不要用单角统计代替整链。
4. 建立内部模型类型及独立 validator，再加 C1 OLS/相位中位/L1 精化；依次参考 1082/1087/1088 的完整结果，最终验收 112 ID 全部恢复。源码中不得出现这些 frame ID 作为算法条件。
5. 在独立校准/测试固定后复现真值精度、负样本与证据篡改检查；不得针对测试集变更 0.5。按本轮原始结果建立可复核的回归约束，不凭通过率改动真值。
6. 验证两次完整 raw 输出一致，全部 CTest、公开接口/布局不变、原图未被修改；顺序重复计时与完整 profiling。硬要求同时检查原平均耗时降低、长尾没有被隐藏，不把无实测的下一阶段优化写进承诺。

本方案没有要求修改三 L 几何、M/S 补全、语义阈值、稳定历史、公开 Detection 或发布逻辑。C1 接入后帧 382 自动恢复的事实避免了额外 D 改动。
