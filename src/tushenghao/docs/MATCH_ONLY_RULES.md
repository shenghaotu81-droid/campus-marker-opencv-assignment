## 2. 输入和结构

外框是当前图像内三L一短M真实白片共同构成的80×80 MARK四边形，不是外板boundingRect。匹配器只输出凸环四点；S片可作空间桥，无仿射、hypothesis、补片或历史预测。四个不同完整角片、六边一凹/正确外凸角、22/80长短分界、全原弧约束是图案确认本体。保持六个简化尺度；拓扑限6点或7→6，不枚举8点组合。

完整性由实际匹配是否存在表示；不存在不拟合，存在还必须有当前原图的真实支持。截断/缺片不能用标签补全。匹配器不赋P身份。

## 3. 身份与拟合

按屏幕坐标排序为LT/RT/RB/LB后查显式P→屏幕排列，当前[0,1,2,3]；安装后核验一次并覆盖预期小抖动。换装可改配置，不逐帧用几何能量或短M位置猜P号。不得跨越排序带交换的适用域。

四边形顶点直接给每角两条邻边方向。对当前原图真实角片取最近轮廓锚点，沿两侧连续轮廓按这两方向分组，起止修剪避免圆角/栅格转折；每组一次L2拟合，两线交点即角点。一组候选，不枚举、不排名、不判角点歧义，不用周期后备。组件不可复用、支持连续且不重叠、两点非零跨度、平行/非有限与float发布后的图界/凸环保护保留。支持构造的3px半窗、2px修剪和随bbox尺度探针不是拟合后的拒绝门，但需在不同设备像素尺度重验。

不输出CornerEvidence、残差/角误差/extension质量旗、空confidence或派生bbox。粗框不能代替精角，PnP/G4不得倒灌成当前检测。

## 4. 位姿与跟踪衔接

G2内部保留IPPE全部数学合法解，独立复算RMSE；无绝对误差/0.25差距门。公共输出只有可选名义估计与平移分歧S，不再区分Unique/Ambiguous；estimate有无值生成ESTIMATED/UNAVAILABLE。无解或坏输入不输出估计，故障原因在已有reason中。

G4直接接名义平移和S，用R_profile+S更新，不挖候选、不重做选支。G3只消费G4的状态/位置/速度/P，当前不添加无人消费的独立歧义标签。
G4保留CV数学、实际NIS排序、两时刻速度初始化、数学异常不提交和coast；删除NIS/std/dt经验拒绝及资格标签。所有输出是相机系名义状态，预测与实测明确区分；没有本片/板端实测profile时不填假的生产噪声。

## 5. 验证原则

检测覆盖与PnP残差必须对比f1ee955；完整1676帧、4352角全部复跑，并保留旧784/P1实拍反例测试。不得按帧号触发特殊分支，不为较好残差容忍漏检测。当前精度证据、旧4360指导输入的失败例、结构尺度消融与MaixCam待验项全部写进修改报告；缺少独立真值的指标只能称内部一致性/重投影残差。
