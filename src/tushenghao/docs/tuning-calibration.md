# 调参与标定记录

## 当前初值及来源

跟踪输出为相机系位置和表观速度，使用固定的基础 $R_{profile}$、连续白加速度 PSD $q$ 和初速先验方差。以下参数来自运动与像素误差的量级估算，当前录像没有独立位移或速度真值。

| 参数 | 初值 | 依据 |
|---|---|---|
| 基础 R 横向分量 | 每轴 `2e-8 m²`，标准差约 0.14 mm | 基准距离约 1 m，由像素误差、焦距和距离传播作量级估算。 |
| 基础 R 纵深分量 | `2.5e-7 m²`，标准差约 0.5 mm | 一阶尺度估计。取该方差相当于假定有效尺度像素误差约 0.1 px，依赖角点联合拟合和相关性。 |
| q | `0.5 m²/s³` | RMS 加速度估为 0.5–1 m/s²，相关时间约 0.5 s。用 $q\approx 2\tau\sigma_a^2$ 作白噪声等效估计。 |
| 初速先验方差 | `0.25 m²/s²` | 根据约 0.5 m/s 的运动量级取标准差 0.5 m/s。首量测没有速度测值，后续成功关联以区间差分初始化速度。 |

角点误差在固定姿态和焦距附近的一阶传播，可给出横向方差随距离约按 $z^2$ 增长、深度尺度误差的方差约按 $z^4$ 增长的近似。遮挡、姿态变化、畸变、视角引起的可见跨度及角点相关性都会改变这一口径。现行实现的基础 R 保持固定，位姿多解分歧 $S_{pose}$ 逐观测附加。距离相关 R 和自适应 Q 都是曾讨论的后续方向。

## 静态记录与像素噪声

在固定相机、固定 MARK、固定曝光条件下采样，再改变距离与姿态重复。记录每角点的 x/y、名义平移、分歧项和重投影残差。相对均值的平移波动只能说明该工况下的重复性。绝对偏差需要独立参考，跨帧相关和多解切换也应单独观察。即使关闭分歧加成，静态平移方差也不能直接当作最终生产 R。

候选似然用的单坐标像素标准差，应从八路角点重复采样估计。内部标定的约 0.095 px 重投影残差和作业视频约 0.36 px 的名义位姿 RMSE 中位数口径不同。动态逐点残差可作为另一组对照，同时含位姿拟合影响。位姿和速度合格范围应使用独立测量或具有已知真值的受控场景核对。

## 动态记录与 NIS

原调参设想包含约 0.5 m/s 的匀速段、换向及往返。匀速段便于观察稳态抖动及模型下的残差，无法独立识别 q 的下界。转弯、加速、制动和遮挡恢复用于检查滞后、过冲及速度收敛。可从 $q=0.5$ 向两侧作对照，固定其余参数和输入。q 偏小可能让换向跟随变慢，q 偏大可能把检测抖动带入轨迹。橙色投影点和 100 ms 速度箭头可以定位现象，定量验收仍用同步的独立位置与速度数据。

NIS 来自修正前的残差和 $HP^-H^T+R$。修正后残差已使用本次量测，不能替代预测一致性检查。若三维新息为零均值高斯、协方差正确且样本未受筛选，NIS 的理论均值为 3，99% 分位约 11.34。实际只记录有成功关联时的 NIS，最低分选择可改变分布，长时间相关及少量异常也可影响均值。长期偏大可能来自低估噪声、转向未建模或系统偏差，偏小可能来自噪声设得过大或候选筛选。均值接近 3 只能作为诊断信号，不能单凭它识别 Q/R 或证明协方差可靠。P 仍是模型给出的估计误差协方差，建议同时检查创新的均值、自相关和分布，以及留出场景上的真值误差与覆盖率。
