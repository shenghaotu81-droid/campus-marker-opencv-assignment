# 视觉管线 API 与推导

## 像素、轮廓和角点

OpenCV 图像的列是宽、行是高，原点在左上，x 向右、y 向下。视频帧是二维 BGR8。BGR 三通道转灰度时，常用亮度近似为 $0.114B+0.587G+0.299R$。阈值分割将强度大于阈值的像素置白。工作图的白阈服务于粗匹配，原图的白阈服务于边拟合。具体值由配置给出。

`resize` 生成新的工作图，按目标宽高确定比例 $s_x,s_y$，默认双线性插值。坐标换算既不会重采样，也不会复制像素。以 x 为例，原图到工作图为 $(x+0.5)s_x-0.5$，逆向为 $(x_w+0.5)/s_x-0.5$。y 同理。整数索引代表像素中心，半像素项保证两个坐标格的像素中心定义一致。工作图提供搜索位置，最终像点来自原图测量。

`findContours` 用 `RETR_EXTERNAL` 仅返回外轮廓。粗匹配的 `CHAIN_APPROX_SIMPLE` 压缩水平、竖直和对角线段，保留端点。边拟合用 `CHAIN_APPROX_NONE` 保存逐点的轮廓索引。一帧的原图轮廓延迟到第一次查询时建立，多个角和多个匹配共用。轴对齐外接矩形为 $[x,x+w)\times[y,y+h)$。触边意味着可能不完整。查询粗角与轮廓的距离时，`pointPolygonTest(..., true)` 返回带符号的最近边欧氏距离，内部为正、外部为负、边上为零。这里只比较绝对值。传 false 时只返回内、边、外三种分类。

点 $p$ 到线段 $ab$ 的最近点为 $a+t(b-a)$，其中 $t=\operatorname{clamp}((p-a)\cdot(b-a)/\|b-a\|^2,0,1)$。两端重合时用距离 $\|p-a\|$。轮廓多边形的有向面积两倍是鞋带和 $A_2=\sum_i (x_i y_{i+1}-y_i x_{i+1})$。将相邻边叉积与 $A_2$ 相乘后，凸点为正、凹点为负，退化边或零面积产生零值。这是在消除绕向带来的符号差别，乘积的大小仍与坐标尺度有关。图像 y 轴朝下，视觉上的左右转与数学坐标系的口径不同。

工作图白片按外接矩形间距分组，组合轮廓取凸包。矩形间隙沿两轴分别计算，再以欧氏距离判断邻接。六种 `approxPolyDP` 尺度用于组轮廓和角片。角片在简化后须为六边一凹，且最近外角与凹点下标差 3。七点时逐个尝试省略一顶点，并沿原弧确认每点距对应合并边不超过 epsilon。四个粗角各绑定不同白片，按朝两条邻边的投影跨度区分短 M 和三 L，S 片可以起空间连接作用。阈值 $22/80$ 来自结构尺寸占比，透视下只是近似。

原图边拟合从离粗角最近的轮廓点出发。两邻角给出单位指导方向，轮廓向两侧各探一段距离，选点积最大的方向组。随后每侧只收集首段连续支持，切线方向用前后各 3 个轮廓索引的点作差，按绝对点积分组。循环索引通过模运算绕回，搜索不跨过半圈。首段跳过 5 像素累计弧长，末端裁去 2 像素。两侧探针落在同一方向组时，当前指导不足以区分两条边。每边用 `fitLine(DIST_L2)` 最小化到直线的垂距平方和，得到方向 $(v_x,v_y)$ 与线上一点 $(x_0,y_0)$，L2 为闭式求解，`param`、`reps`、`aeps` 不用于这条路径。若直线为 $a+tv$ 和 $b+sw$，对等式与 $w$ 取叉积可消去 $s$，得 $t=((b-a)\times w)/(v\times w)$。代码限制分母有限且足够大，并检查交点有限。

粗角排序后按安装表转物理顺序，精修角再以 float 精度复核，并发布屏幕顺序 LT、RT、RB、LB 和 `orientation_`。double 降到 float 后再升回 double，便于在实际可表达的角点值上检查。排序策略先按 y 分上下两组，再按 x 分组内次序。凸性检查作用于排序前的输入环，排序后仍有可能遇到不适合安装约定的环，因此平面求解对实际送入的点序复核。位姿端按 `pixel[p] = corners[orientation[p]]` 恢复物理环。

## 相机标定、PnP 和候选分歧

相机坐标系光心为原点，x 右、y 下、z 向前。主点 $(c_x,c_y)$ 是光轴与像平面的交点在像素坐标系中的位置。它可以偏离画面中心。MARK 模型的米制原点位于模型左上角，x 沿上边向右、y 沿左边向下。Tag 模型的原点在中心，方形角点依库返回顺序对应 $(-h,h),(h,h),(h,-h),(-h,-h)$，$h$ 为实物边长的一半。

外参把模型坐标转成相机坐标 $p_c=R p_m+t$。Rodrigues 向量以方向表示旋转轴、模长表示弧度角。$t$ 是模型原点在相机系中的位置。将 $p_c$ 按 z 归一化得 $(x,y)=(X_c/Z_c,Y_c/Z_c)$，先加模型畸变再由内参映射到像素。$K=[(f_x,0,c_x),(0,f_y,c_y),(0,0,1)]$，$f_x,f_y$ 是以像素计的焦距。常用五参数按 $k_1,k_2,p_1,p_2,k_3$ 存储。令 $r^2=x^2+y^2$、$g=1+k_1r^2+k_2r^4+k_3r^6$，畸变后坐标为

- $x_d=xg+2p_1xy+p_2(r^2+2x^2)$
- $y_d=yg+p_1(r^2+2y^2)+2p_2xy$
- 像素为 $(f_x x_d+c_x,f_y y_d+c_y)$

反向使用 $K^{-1}$ 和迭代去畸变可恢复归一化光线 $(x,y,1)$。平面 PnP 求和这些光线相符的旋转与平移。标定内参与图像尺寸绑定。求解器复制 K、dist，防止外部 Mat 修改共享像素存储。

`solvePnPGeneric` 用 IPPE 对共面点给至多两个候选，基于实际返回的旋转和平移数组循环处理。调用不使用外参初值，也不读取 OpenCV 的候选误差。通用迭代 PnP 则通常返回一组外参。OpenCV 通过 InputArray/OutputArray 接收 Mat 或 vector，`noArray()` 省略可选量。程序将每个 $3\times1$ double Mat 拷入定长 Vec3d。实物四角所有相机系深度须为正，再用 `projectPoints` 做独立复投影，按点数计算二维 RMSE $e=\sqrt{\sum_j(\Delta u_j^2+\Delta v_j^2)/n}$。投影的可选雅可比描述像素对外参、内参和畸变的导数，aspectRatio 可在求导时固定 $f_x/f_y$。本链不使用这些可选输出。深度取累计最小值，投影阶段另外检查距离与 RMSE 有限。标定工具也独立用全部成功点对重算二维 RMSE，与 `calibrateCamera` 的 RMS 交叉核对。

名义解选最小 RMSE，精确平局取最先返回者。其余候选的平移差为 $\delta_j=t_j-t_0$，以 $w_j=e_0^2/(e_0^2+e_j^2)$ 累加 $S_{pose}=\sum_{j\ne0} w_j\,\delta_j\delta_j^T$。代码先除以较大误差再平方，二者为零时取等权。单解时矩阵为零。每个外积是秩一半正定项，沿单位方向 $u$ 的贡献为 $w_j(u^T\delta_j)^2$，垂直于差向量时贡献为零。它是以名义平移为中心的加权二阶矩，按当前模型加到基础位置噪声 $R_{profile}$。它不包含旋转不确定度，权重也没有经过后验概率校准。

备用方案曾考虑 $w_j\propto\exp[-n e_j^2/(2\sigma^2)]$。在各坐标独立同分布、方差为 $\sigma^2$ 的高斯像素噪声假设下，残差平方和为 $n e_j^2$，其中 $n=4$，再以相同先验和归一化给出候选间的相对似然权重。若用按 $2n$ 归一的每坐标 RMS，代入时应用 $SSR=2n e_{coord}^2$，四角时指数为 $-4e_{coord}^2/\sigma^2$。直接求指数可能下溢，可先减去最大对数似然再归一。0.095 px 标定拟合残差与约 0.36 px 的录像 PnP RMSE 中位数都不能直接代入为单坐标 $\sigma$。计划是固定相机及目标，按四角的 x/y 共八路统计重复采样的标准差，再用动态逐角残差作为有额外误差源的对照。动态残差不能当作严格的噪声上界。原比较备选为固定 R、逆平方分歧、似然分歧、PDAF、去掉分歧项。这些备选属于待实验裁决。

## 匀速滤波的状态、共变和关联

方差是偏离均值的平方的期望 $\mathrm{Var}(X)=E[(X-E[X])^2]$。有限样本经验方差可用 $\sum_i (x_i-\bar x)^2/N$ 计算，无偏样本估计通常用 $N-1$。标准差是方差的平方根。零均值误差向量的协方差为 $P=E[ee^T]$，线性变换 $y=Ae$ 得 $\mathrm{Cov}(y)=APA^T$。单位方向上的投影方差 $u^TPu=E[(u^Te)^2]$，三维展开包含三个对角项和 $2u_xu_yP_{xy}$、$2u_xu_zP_{xz}$、$2u_yu_zP_{yz}$。零交叉协方差一般只意味着不相关。特征向量为椭球主轴，主轴方差是对应特征值。对 $e^TP^{-1}e=1$ 的椭球，径向平方为 $1/(u^TP^{-1}u)$，仅在特征方向与投影方差相等。迹等于方差之和。基础 R 的三轴对角值来自 profile，加入位姿分歧后实际 R 可有非零非对角项。

滤波器状态 $x=[p,v]^T$，$P$ 为 $6\times6$。首量测写位置，速度以零均值与 profile 方差初始化。下一次成功关联通过 $(p_1-p_0)/dt$ 估计区间平均速度，缺测可使两次量测相隔多帧。假设两个位置噪声互不相关，初始位置、速度和交叉协方差分别为 $R_1,(R_0+R_1)/dt^2,R_1/dt$。因为速度估计用于第二个时刻，额外补入白加速度引起的端点差。区间均速的加速度权重是 $(dt-s)/dt$，末端速度权重是 1，二者的差权重是 $-s/dt$。其方差为 $q\int_0^{dt}(s/dt)^2ds=qdt/3$，加到速度块对角。

预测用 $x^-=Fx$、$P^-=FPF^T+Q$，$F=[(I,dt I),(0,I)]$。白加速度的强度 $q$ 单位 m²/s³。每轴在区间内位置的加速度权重为 $dt-s$，速度权重为 1，乘积积分产生 $Q=q[(dt^3/3,dt^2/2),(dt^2/2,dt)]\otimes I_3$（按位置、速度分块）。该式来自连续白噪声模型。离线 dt 来自严格递增的整数微秒时间，时间差先用 long double 相减再转秒，避免在整数运算处损失范围。

观测矩阵 $H=[I\;0]$。新息 $\nu=z-Hx^-$ 是位置量测与预测之差。若量测误差和先验误差不相关，则 $\Sigma_\nu=HP^-H^T+R$。左右乘 H 分别截取 P 的前 3 行和列，所以实现只需位置块。NIS 为 $\nu^T\Sigma_\nu^{-1}\nu$，即残差的平方马氏距离。Cholesky 分解 $\Sigma_\nu=LL^T$ 后，白化 $y=L^{-1}\nu$，NIS 等于 $y^Ty$。在新息高斯、零均值、协方差正确且样本未经过关联筛选的假设下，三维 NIS 服从 $\chi^2_3$，均值 3，99% 分位约 11.34。实测输出是关联后的样本，统计口径需另说明。生产使用最低 NIS 排序，最低分精确平局时沿用预测。实现通过 `solve` 求 $\Sigma_\nu s=\nu$，再算点积，避免显式求逆。LU 可用于一般方阵，Cholesky 要求对称正定，SVD 处理更宽泛的矩阵情形。

修正时 $K=P^-H^T\Sigma_\nu^{-1}$。代码先解 $\Sigma_\nu K^T=(P^-H^T)^T$，再转置。状态为 $x^+=x^-+K\nu$，速度通过 P 的位置–速度交叉块随量测更新。Joseph 形式为 $P^+=(I-KH)P^-(I-KH)^T+KRK^T$，用最优增益在精确算术下可化至 $(I-KH)P^-$。两项半正定，和是否严格正定取决于误差方向是否都受约束。实现对结果对称化后再验正定。检查用无穷范数比较不对称量，容差取机器 epsilon、矩阵维数与 $\max(1,\lVert P\rVert_\infty)$ 的积，再检查降序特征值的最小项。状态推进在副本上执行，非法帧或计算异常时不提交。

## C++ 与 OpenCV 接口速查

- Mat 是可拥有或借用动态缓冲的矩阵头。普通复制共享缓冲，`clone()` 深拷贝。Vec/Matx 的固定大小数据内联在对象里，对象可以有不同存储期。Mat 从 Vec/Matx 构造默认 `copyData=true`，显式 false 时借其原存储。给 `cv::Mat(x,false)` 执行 `copyTo` 可写回定长对象。Mat 的 `at<double>(i)` 用于已知的一维向量访问，`at<T>(row,col)` 用于二维索引，调试断言受构建模式影响。
- Matx 的 `*` 表示矩阵乘法，`mul` 为逐元素乘法，`dot` 为内积，三维 Vec 的 `cross` 为叉积，`t()` 转置。列向量 $d$ 的 `d*d.t()` 为外积。Mat/Matx 的 `zeros`、`ones`、`eye` 分别生成全零、全一和单位阵，Vec 的 `all` 将每个分量设为同一值。Mat 的运算表达式可以延迟求值。
- `FileStorage` 的 `!!opencv-matrix` 以 rows、cols、dt 和按行排的 data 存矩阵，dt 为 d 时是 double。帧号、微秒时间和计数写十进制字符串，以保留 64 位精度。YAML 跟踪流的 `state_time_us`、`last_measurement_stamp.frame_id` 和 `received_us` 遵循这一约定。NIS 和速度字段按可用性写出。
- Optional 在条件中按是否含值转换为布尔。非空后可用 `*` 或 `->` 访问，`value()` 对空值抛异常，`value_or` 返回值或默认值，`reset` 清空已存对象，`emplace` 原地构造。条件中声明变量与 C++17 的带分号初始化语句是两种写法。
- C++ 对象用 `make_unique` 独占实现。构造函数按值接收配置，可在入口把副本或临时值移入成员。Pimpl 的析构定义放在实现完整的翻译单元。C 库对象由 `unique_ptr` 配对应的销毁函数，`get()` 只借指针，`release()` 则转出所有权。AprilTag 检测器先注册 36h11 family，再逐帧借用灰度 Mat 的数据指针及行步长。结果数组的 `zarray_get` 通过输出地址拷贝指针槽位，调用方在释放数组前取出像点。边长查 map，ID 查白名单 set。相同 ID 的重复观测整组排除。 `remove_if` 将保留项稳定地压到前面，`erase` 才缩短容器，尾段内容无保留保证。`quad_decimate=1` 时，本机部署接口注明忽略 `refine_edges`。
- `std::sort` 的比较器回答左项是否应排前，`min_element` 返回首个最小元素的迭代器，空区间返回 end。set 插入的布尔返回值表明是否新增，`count` 在唯一键集合里只有 0 或 1。map 的下标对缺失计数键值初始化后再累加，结构化绑定逐项读取名称和计数。捕获引用的 lambda 可在当前函数内直接读写关联变量。
- 离线应用按解码器给出的标称帧率用 `llround(frame_id * 1e6 / fps)` 生成微秒时间。视频 `read` 失败会结束循环，真实运行耗时由单调时钟与 `duration<double>` 取得。文件系统的 `parent_path` 和 `stem` 用于将输出映射到同目录的 `<stem>.partial.avi`。VideoWriter 使用 FFmpeg/MJPG，先 release 再改名。回放验证编码器实际产出的完整性。控制台接收通用 ostream，也可注入文件或字符串流。
- 绘图用原图克隆作为画布。OpenCV Scalar 的颜色顺序为 BGR，`{255,255,0}` 是青色，`{0,255,0}` 是绿色。LINE_AA 是抗锯齿，绘图默认坐标 shift 为 0，圆的负厚度表示填充。字体用 Hershey，文字定位给基线起点。轨迹数值用 fixed 三位小数，速度箭头取位置加 100 ms 速度位移，以相机系直接投影，只表示可视长度。名义位姿重投影只反映与当前检测角点的拟合。
