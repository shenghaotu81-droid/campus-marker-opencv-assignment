## 判断：可以去掉仿射，但要明确四边形是什么

赞成目标接口只接收边、身份和完整性，不再接收仿射或 hypothesis。模型中的目标结构角为 P0=(0,0)、P1=(80,0)、P2=(80,80)、P3=(0,80)，单位 mm；四边形对应这些结构角时，相邻顶点的连线与当前拟合所找的两条物理外边共线。此时直接从顶点取邻边，比“先推仿射，再投影模型邻边”少一次间接计算，没有必要为了生成边重新建立仿射，也不建议换成另一个变换矩阵。

这个结论有三个条件，不能由一个任意四点数组自动保证：

- **四边形必须围住这四个结构角。**外板的 115×120 外轮廓不等于 80×80 的 MARK 结构角；如果“外框”指外板，其边不能直接替代当前被测边，需要先重新定义目标边。代码依据：`config/marker_geometry.yaml` 和 `include/vision/types/marker_geometry.hpp`（路径相对 `src/tushenghao/`）。
- **固定映射必须由 match-only 输入契约保证。**只按屏幕左上、右上、右下、左下排一个正方形，不能唯一确定物理 P0。上游可以保证顶点已经按物理身份排列；拟合不再搜索身份，但不能自行猜出身份。以后仍需要图案匹配等规则，不能以“四边形存在”替代方向识别。
- **外框存在须表示一次完整的当前帧匹配。**不能把任意矩形包围盒、局部遮挡后补出的框或截断框视作完整目标。可以取消复杂的 hypothesis 完整性枚举，改为上游“有完整四边形／没有”的契约；拟合仍检查原图中两边的实际支持，缺边不补角，交给 G4 coast。

因此赞成“最终只有四边形 + 拟合”，但不赞成“任何外框的四个顶点都足以保证原来的身份、支持域和精度”。上述条件要写进替代检测规则，再实施本建议。

## “精度”分别指什么

| 指标 | 定义与用途 | 不能据此推出的结论 |
|---|---|---|
| 角点定位误差 | 原图中的拟合交点与独立标注／已知投影真值的欧氏距离，单位 px；分别统计 P0…P3 的偏差、中位、P95/P99、最大值 | 两版交点一样，只能证明重构没有移动结果，不能证明真实误差为 0 |
| 拟合残差 | 支持像素到物理直线的平均／最大垂距；周期模型的校正残差另外记录，单位 px | 残差小不意味着选对了物理边；短弧可能得到很小残差但交点不稳定 |
| `corner_error_px_` | 交点到实测转折连接弧的距离 | 它不是到真实物理角的误差，不是概率或协方差 |
| PnP 重投影 RMSE | 用固定 K/dist 和模型，将候选位姿重投影回四个像点，四点二维误差平方均值的平方根 | 小 RMSE 不保证角身份正确、深度真实或平面解唯一，不能代替独立角点真值 |

用户给出的现状好解中位约 **0.43px** 是 PnP 指标，不是角点定位精度。本批松门后、路线合并前后的同样本复跑，中位均为 **0.3915354321px**：口径是 1088 个检出帧中，合法正深度候选的最小 RMSE，仅用于对比；实际输出仍全部是 Ambiguous，未将该候选强行发布为 Unique。这与历史 0.43px 的样本和筛选口径未完全对齐，不能据此宣布精度提高。

## 现状结构

1. `corner_resolver.cpp` 从 hypothesis 的 `assignments_` 找 L0/M1/L2/L3，用 `affine_transform_` 投影图纸邻边，再从当前原图关联组件轮廓。
2. `corner_edge_fit.cpp` 在完整有序轮廓上找连续支持弧，裁转折附近点，按指定边的方向、位置和实际跨度选支持；对两条边拟合，求交点并排除相互冲突的解释。本批删除完全重复的尝试后仍有 11 个不同尝试，包含普通 L2 和周期模型。
3. `CornerEvidence` 保存帧、片段、完整支持弧、模型参数、交点、各类误差及延伸量。数值质量超限不会直接删角，发布为 `Detection.quality_flags`，并随 MARK 位姿保留。
4. `corner_evidence_validation.cpp` 在生产中做来源、完整性和数值合法性检查；完整像素重拟合与 claimed 值比对已移到测试中的 `corner_evidence_check.cpp`。

现状繁琐的主要原因，是上游候选对应、有限模型边、连续轮廓弧别名、多个估计器及历史复核证据叠在同一条输入链上。把入口改为四边形，能去掉前两类依赖；其余每项是否可删，还要独立验证。

## 目标结构：输入、拟合、输出

**输入**：当前帧原分辨率图像／二值观察，按 P0…P3 排好的四边形，以及当前帧身份。四边形不存在就不调用拟合；存在时其四条边直接为 `(q[i], q[(i+1)%4])`。对第 i 个角使用前一条边与后一条边作为搜索提示，不再传仿射、模型片段对应集合、hypothesis 或竞争假设循环。

四边形顶点是粗定位，不是最终测量。原图像素不能省：拟合应在两条邻边附近找真实边支持，保持局部支持来自目标边。四边形整条边跨越了白片间黑色间隙，不能把间隙或远处 S 白片的边拼成一个不存在的连续角支持。

**拟合**：局部原图观察 → 两条边各自选支持、拟合直线 → 检查可求交性及支持来源 → 求实测交点 → 计算质量标签。保持四角的物理顺序，最后由现有排序／发布模块转换屏幕序。G2、G4 仍为独立消费者，不把 PnP 或历史预测反向塞进当前角点。

**输出**：四个原图 double 交点、固定物理身份、必要来源与完整性信息、每条线残差／支持跨度、交点到连接弧距离、延伸量和质量标签；不足以形成四个当前实测角时输出未检出，由 G4 coast。公开发布前仍检查有限、严格凸、原图范围、映射和 float 表示。

这里的“只有四边形 + 拟合”描述算法主干，不意味着可以删除像素输入、数值合法性或质量输出。无需为这个目标另造调度层、策略注册表或新的中间模型。

## 具体简化、精度理由与风险

| 建议 | 为什么有望不丢精度 | 风险与需要量测的地方 |
|---|---|---|
| resolver 改接四边形，直接取两条邻边；删除 assignments、仿射投影和 hypothesis 参数 | 边若对应同一物理边，最终仍从相同原图像素拟合、求交；不把粗顶点直接作为结果 | 当前有限模型边较短，四边形边较长；搜索域变化可能引入内边、S 片或背景。必须按逐角支持像素、误配率和真值误差比较，不能只比较方向 |
| 单次处理四角，取消按父候选重复调用 | 上游已唯一给出物理身份时，重复候选不再提供独立测量信息 | 前提是上游已解决歧义；不能简单取第一个框，不能在多个匹配间暗选最小残差 |
| 把支持提取与直线估计分清，减少别名缓存和重复枚举 | 若保留同一支持集合及确定的选优／歧义规则，数学结果可以逐项复现 | 端点相同不代表有序像素相同，回走轮廓与转折裁边会改变权重；先保留独立枚举对照，再删缓存 |
| 先尝试普通 L2，周期模型只保留确实需要的退路 | 普通 L2 在同样支持上数值不变；周期模型仍可解释扫描奇偶偏移 | 本批录像有 1/4360 次使用周期后验路线；直接全删周期模型已有反例。若要进一步合并，须覆盖奇偶相位、轴对称、秩不足和真实片段，不以零命中证明永远没用 |
| 合并重复的路线调度，支持域和估计器保持显式 | 完全重复的尝试删掉不会产生新结果；本批 13→11 已在 1676 帧上证实坐标与 RMSE 不变 | 把原始端点、后验位置、全端点搜索直接并成大搜索，会改变竞争集合和首个成功结果；这种合并需要重新做消融对比 |
| 减少 `CornerEvidence` 重复表示 | 原始弧端点、独立 segment 端点、字符串 stable_id 等存在可推导关系；删除重复存储不会改变拟合所用像素 | 语义层当前用 stable_id 做确定性平局裁决，不能直接删；先明确新裁决键，验证输入顺序不影响输出。生产至少保留精确数值标签与来源，完整像素对账留测试 |
| 质量标签保留，生产只做必要检查 | 不重拟合／不再比对自己的 claimed 值不会改变原始计算结果；测试能独立验证参数和标签 | NaN、近平行、无支持、来源错帧、出框仍不能当低质量成功角；“改标签”不能覆盖数值不可求解或缺观测 |

**不可丢的部分**：两条真实边的直线拟合及其交点；物理身份与原图坐标；足够跨度和不同来源的实际支持；截断／不可求解处理；角点误差、原始与模型残差、延伸量等质量标签；G2 保留 IPPE、多解和原重投影 screening；G4 保留 NIS 与 coast。图像存在畸变时，长边不一定在原图中严格直；保留当前局部拟合口径，不能直接改成整条长边拟合而宣称精度不变。

## 路线合并／重构的方案评估与推荐

**我的首选验证方案是两条互补路线：普通 L2 主路 + 周期相位中位数的后验位置回退，共用支持提取、求交和质量输出。**它比继续维护 11 种尝试更有希望简单，又没有直接丢掉录像里已经出现的失败模式。它是下一轮重构候选，不是本批已经实施、也不是已经证明所有场景等精度的方案。

依据分两层，不能混用：

- 在 1676 帧、4360 次候选角拟合中，Legacy 主路成功 4359 次，约 99.977%；唯一一次回退是 **frame_id=784、hypothesis=0、P1**，使用原路线 4，即 PhaseMedian + 后验位置。普通主路独自处理全部输入的方案已经有一个现成反例。
- 本批 13→11 删的是完全重复尝试，保留了其他支持域与模型；4360 次坐标、残差、延伸及完整 PnP 文件保持一致，确认了这次机械合并无损。这个结果不能外推为“11→2”或“四边形输入替代”也一定无损，后两项必须另跑。

| 候选方案 | 简化收益与精度判断 | 对实际失败模式的覆盖与结论 |
|---|---|---|
| 单条普通 L2/TLS | 模型最少，当前绝大多数结果可直接复用；支持不变时可逐项复现 | frame 784 的 P1 需要现有周期后验回退。除非新四边形支持选择确实解决它且交点/PnP 不退化，否则不选为唯一生产路线 |
| **两条互补路线：L2 + PhaseMedian 后验回退** | 不给 99.977% 的成功主路额外增加自由参数；少数失败才使用已有实证的周期修正，共用所有其他步骤 | **优先推荐进入对照实验。**保留实际出现的“普通主路失败、周期后验可恢复”场景；奇偶偏移与支持位置各自的影响仍需核对。对圆角、碎边、缺边及全端点反例还须逐项验收，不能因为录像零命中便认定已覆盖 |
| 保留小回退集合 | 在上述两条之外，仅对被独立反例证明必要的支持扩展或估计器增加一项 | 作为两条方案的退让选择；例如某个实际碎边样例必须全端点才恢复，就保留该支持扩展。每条附具体失败输入与收益，避免恢复成无依据的路线堆叠 |
| 单条统一的周期线性模型（普通直线是奇偶系数 c=0 的特例） | 表面上一种模型，但 c、扫描轴及秩检查仍存在；它会改变原先 4359 次普通拟合的估计方差和交点 | 有可能统一普通／双相位像素，但不能用“残差更小”证明角点更准。满秩、单相位、短弧退化通常又需要降阶处理；列为第二优先级实验，不优先于已有实证的两条方案 |
| Huber、L1 等稳健直线拟合 | 可能抗少数离群像素；替换估计器会改变支持权重，需要重新量测角点偏差 | 对周期性双边像素并非一般离群点问题，不保证解决 frame 784；Huber 的尺度或额外收敛设置也有成本。有真实污染支持的反例时再考虑，不因名称“稳健”直接替换 |
| RANSAC、Hough/LSD 等先找线再求交 | 能跨间隙或从杂乱图中找线，但仍要解决物理边关联、内外平行边和精确重拟合 | 引入采样／量化／共识阈值或新的线检测、关联步骤，通常不是更简单。若外框已给出可靠边，先利用这个信息缩小支持域，更合适 |
| 四边联合优化、强加正交／平行、直接以 PnP 误差调角 | 可以减少局部自由度，也容易得到很低的重投影残差 | 透视图像里的邻边不必 90°，原图畸变下长边也不严格直；硬约束会产生系统偏差。用同一四点模型调角再用 PnP RMSE 验证会形成自证循环，不作为当前首选 |
| cornerSubPix／直接灰度角点／圆弧模型替代 | 有潜在亚像素能力，但需要匹配成像和边缘模型、窗口与初值范围 | 圆角、M 分段、奇偶扫描和断边未必满足局部标准角假设；纯角点替代也不满足当前保留直线拟合交点的约束。可作独立真值对照或另行研究，不把它当“函数少就更准”的捷径 |

推荐的两条方案应尽量保持**一份支持提取、一份直线求交、一份质量输出**。差异只在确实需要的线估计和位置解释；不再给每条路线复制 resolver、证据结构或验证器。新的四边形输入有望缩小候选域，但不能直接把原始／后验／全端点的支持集合简单并成全集：新增候选可能触发几何冲突或改变首个成功结果，进而改变精度。

回退触发先沿用“主路没有合法可求交的观测支持”这一类明确失败，不新增经验阈值，也不将已经改成标签的 max_corner_error / extension 门偷偷变回拒绝门。主路虽成功但质量标签差时，仍把标签交给下游；如果未来要比较两个成功模型再择优，必须另外证明选择规则不会用更小的拟合残差掩盖更大的真实角点偏差。

具体取舍可以由现有材料直接裁决：先固定现有输入和支持定义，只做路线消融，比较主路、两条、小回退集合、统一模型；对 frame 784 的 P1 单列坐标、支持、模型残差与两组 PnP 候选，并完整复跑 1676 帧和现有反例。再单独切换四边形输入，以免把“换输入”和“删路线”的影响混在一起。检出覆盖、物理身份、共同样本角点偏差与 PnP RMSE 均不退化后，才选择最少路线数；若两条已通过，优先用两条，若一条也通过同样的检验，再进一步减到一条。

录像无独立角点真值，因此当前只能对删除重复路线给出已经完成的无损结论。两条方案是基于真实命中与复杂度的最佳起点；证明它在绝对定位精度上不下降，仍需已知投影真值样例或可靠标注，以及后续板子录像的分布验证。当前不需要为这些候选引入新框架或训练模型。

## 建议验证顺序

1. 固定本批合并后的提交、K/dist、模型、分辨率与所有数值参数作为基线，先记录检出／未检出／歧义的帧集合、角身份、支持像素、交点、全部 PnP 候选和路线命中。
2. 替代检测规则先交付真正的 match-only 四边形及物理序契约；在其结果上验证边与当前物理边一致。没有该输入时，不以假定的新框实现重构。
3. 一次只做一种简化。纯删除重复计算，应在相同输入上逐项复现交点和 RMSE；改变支持选择的简化，须增加独立真值／标注，比较逐角偏差、P95/P99、最大值及失败帧，不能只看总体中位。
4. 每一步在现有 **1676 帧**录像上完整复跑，分别报告共同检出帧与各自全部检出帧的统计，防止通过少检难帧让 RMSE 看起来更低。同时比较身份、边支持、Unique/Ambiguous/NoSolution 计数及 G4 更新／coast；有变化时列出具体帧。
5. 补充现有圆角、碎边、缺边、出框、奇偶扫描、回走轮廓、近平行、float 排序和篡改证据测试。真实录像没有独立角点真值，不能单独承担绝对角点精度验收。
6. 在目标板录像上复验分布和耗时；预算按既定 fx 比例缩放，不在重构时擅改阈值。新的支持域若需修改数值预算，另行提交量测依据供用户审阅。

没有独立角点真值时，最多确认与既有实现的一致性、PnP 指标和覆盖率；不能承诺新的 match-only 结构已经保持物理定位精度。是否实施、实施哪些进一步简化，由用户审阅本建议和替代检测规则后决定。

## 本轮实施后的方案评估回填

用户随后授权实施match-only与路线重构，当前结果以[MATCH_ONLY_REFACTOR_REPORT.md](MATCH_ONLY_REFACTOR_REPORT.md)为准，前面的“待实施”是历史状态。

本轮自由比较后推荐并实施：**四边形直接给边＋普通L2主路＋周期后验回退，同一路线中加入支持长度排序分数**。只用单路虽然覆盖新四边形录像全部4352角，却会丢掉冻结旧输入中的已知可恢复反例；保留第二路成本小，且不强迫新设备满足周期噪声假设。原13→11的统计只能说明当时命中，最终依据是旧4360输入消融、真实新入口、独立真值和负样本共同验证。

保留原残差排序的两路初版在合成共同集约有0.004px小幅上升，因此未直接采用。简单的支持长度排序使共同172角的中位误差保持0.427637px，P95从0.789776降至0.745010px，最大从0.963515降至0.922374px。另一种加量化噪声底／外推杠杆的评分公式更复杂且均值略差，不推荐。最终1676帧PnP中位／P95／最大值三项降低，检出帧集合不变；各帧仍可能增减，真实录像无独立角点真值。

Huber、RANSAC、梯度亚像素定位、全局受约束模型和学习方法都可以考虑，但本轮没有实施或冒称其精度已验证。MARK短M支持有限、图案断开，不能照搬通用完整边框检测；新方法必须证明对实际新失败模式有收益并在MaixCam／现有录像上量测。当前证据支持最简单的两路方案；若板端出现新的失焦、畸变、反光或相位结构，再用具体反例评估这些候选，不预先扩张模型链。
