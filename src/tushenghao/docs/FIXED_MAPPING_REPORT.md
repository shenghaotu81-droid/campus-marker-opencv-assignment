# 固定安装映射：实现与完整验证

分支refactor/vision-lean-fixed，基线10eae9b。开始时已在该分支、HEAD正确、工作区干净；main、refactor/lean、refactor/vision-lean均不改。此交付替换身份确定和屏幕排序步骤，检测完整性、两路拟合数值、G2与G4逻辑和阈值不改。

## 判断与适用条件

认可在用户给定的固定安装、水平轨道、小晃动条件下使用固定映射。最新V1.0.3规则§3.3.3（PDF第14页）规定视觉标签与地面垂直、位于兑换框正对移动区域一面；它没有保证相机图像绝不旋转，固定朝向是这套部署经安装验收建立的契约，而非比赛规则对所有安装的普遍保证。尺寸仍为80×80mm白片结构、115×120mm识别板，参见[MATCH_ONLY_RULES](MATCH_ONLY_RULES.md)。

实测10eae9b录像全部1088个检出帧的物理→屏幕映射均为[0,1,2,3]。上两角与下两角的最小纵向间隔为174.201599px。因此小晃动不需要“最上点就是P0”，只要上下两带分离、各带左右不交换，屏幕槽位就稳定。测试覆盖±10°排序／发布、±8°真实图案匹配和多工作分辨率；不是宣称任意视角或±10°以外必然失败／成功，也没有添加角度门。

## 配置与独立步骤

```yaml
detector:
  corner:
    physical_to_screen: [0, 1, 2, 3]
```

数组下标是P0/P1/P2/P3，值是LT=0、RT=1、RB=2、LB=3。三份detector YAML均显式填写。加载要求恰四个整数且为0..3排列，缺失、重复、越界、非整数或类型错误报配置错误；导出／重载保留该值。C++配置结构的初值为同一安装映射，调用方可显式替换，不存在自动方向猜测。

1. `geometry/matching/match_quad.cpp`仍用原分割、归组、凸包、六边一凹及三L＋一短M确认完整目标，只输出原图粗定位凸环，无P编号。短M的位置不再决定循环起点，保留短角计数是完整目标检测，不是身份推断。
2. `corners/ordering/screen_order.cpp`是独立坐标排序实现：先y升序取上下两点，再各按x排为LT/RT/RB/LB。保留原有限、重复、凸性与面积前提，不移动任何像素。删除归一化能量、四个循环候选、能量平局与字典序决胜、动态物理映射生成。
3. `pipeline/decode/decode_stage.cpp`编排查表：physical[p]=screen[mapping[p]]，把P序四边形交给原resolver。匹配器不依赖排序实现或拟合配置；排序不访问L/M、图像、PnP、G4或历史；拟合仍只接四边形边和当前原图。替换某步骤须遵守这些值契约，无新抽象层。
4. 拟合后及float舍入后继续坐标排序，发布orientation直接读配置。删除重复ScreenCycleOrder包装、screen_order_tie及永远为true的orientation_unique参数；原质量旗／bbox／数学和边界验证保留。删除旧内部screen_order.hpp，统一用既有corner_types.hpp契约，文件仍位于现有ordering板块。

G2仍按orientation恢复物理序；IPPE、预算1.10/1.10px、差距0.25px不动。G4仍按原NIS与coast处理，生产profile仍空。两条拟合路线、支持提取、求交与质量标签的实现和阈值不变。

## 赛前安装核验（每次换装后重做）

1. 确认显示／摄像头没有额外旋转或镜像处理，原图域、分辨率、K/dist一致；对照MARK图纸，标清P0、短M外角P1、P2、P3。
2. 拍一张完整清晰MARK，按屏幕LT/RT/RB/LB读四角槽位，逐个记录P编号所在槽位，写成physical_to_screen数组。当前作业录像：P0=LT、P1=RT、P2=RB、P3=LB。例：整套相对图像旋转90°的测试装法需[1,2,3,0]；它必须由安装观察给出，不由代码自动推断。
3. 运行marker_app，核对overlay上0/1/2/3标记是LT/RT/RB/LB，并与图纸物理角逐一对照；P1必须落在短M外角，P0/P2/P3也必须分别对照，不能仅凭较低PnP RMSE验映射。模型正方形的循环错号可能依然低RMSE。
4. 在整个水平轨道和预期距离／斜视范围采样，包含可重复的小晃动、端点和比赛照明。检查上两角最大y严格小于下两角最小y、各带左右顺序稳定，四角不切屏、身份不跳。记录最小上下／左右余量，并预留实测晃动余量。这里是安装验证，不增加生产运行拒绝门。
5. 若上下带会交错、发生明显图像翻转／近菱形、相机装法变化或镜像，停止使用该安装映射；重新安装／校准并重做核验。运行中不尝试猜新身份、沿用历史补角或新增G2/G4拒绝门。MaixCam现场需重验这些成像和晃动边界，作业录像不代替实拍。
