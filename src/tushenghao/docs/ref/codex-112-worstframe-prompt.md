# 任务：沙盒最慢帧优化

## 背景

EXECUTION_PLAN.md 已封存：112/112 恢复、均值 34ms 达标。
但最慢帧仍约 5 秒（帧 153 的 L1 精化），不可接受。
`lad-dedup-exploratory.jsonl` 是拐点去重探索版，未进入最终冻结版。

## 目标（硬性）

- **最慢帧降到 33ms 以内**（逐帧稳定 30 FPS，这是真正的目标，不设中间线）；
- 均值同步降到 25ms 以内（给最慢帧留 headroom，现在均值 34ms 本身就超了 33ms）；
- 112/112 恢复不能掉（全视频复测确认）；
- 25/25 回归、独立合成测试、20/20 负样本全部保持通过。

## 探索方向（不局限于此，可自由发挥）

1. 把去重探索版扶正：验证去重后结果与冻结版逐值一致，测新的最慢帧分布；
2. 若去重不够，剖析 L1 精化的 40 次三分搜索 + 斜率拐点枚举，找冗余计算；
3. 考虑斜率搜索区间收紧、目标收敛时的 early termination；
4. 考虑帧 153 这类病态输入的特征检测 + 专用快速路径；
5. 若单帧算法层面已到极限，论证"病态输入 early reject"的判据（必须有数据支撑，不能拍脑袋）。
