## 2. match-only 的含义

“外框”指 **当前帧的 L/M 结构共同形成的 80×80 MARK 四边形**，不指115×120外板，也不是任意 boundingRect。

输入是原图与工作图、原图坐标映射和现有检测配置。匹配输出只有按物理 P0…P3 排列的四个粗定位顶点（可以有多个相互独立匹配）；没有 affine、homography、父假设、部件对应搜索集合、补片、完整性状态枚举或预测角。

完整性由匹配四边形是否存在表达：不存在就不拟合；存在仍要求每角在当前原图中有实际两边支持。粗四边形只是支持搜索提示，绝不直接作为精确角点；不外推缺角，不以拟合预测补全外框。

## 3. 从当前观察直接形成四边形

1. 保留当前白色分割和工作图观察。只使用图像中实际存在的 L/M 轮廓，不访问 PnP、G4 或前帧。
2. 用已有六边一凹的局部拓扑识别 L/M 角片：长臂 L 与短臂 M 由内臂和笔画的相对关系区分，不用固定像素面积猜身份。沿用已存在的多尺度轮廓简化与全原弧约束；这是匹配规则，不是新的误差质量门。
3. 在图像局部将相邻角片归组：间距采用观察到的角片跨度定义，不用作业相机固定距离或固定 ROI。不能把同组里的多个竞争 MARK 静默选成一个；无法分离时保留未匹配，列为重捕场景。
4. 对同一组实际角片的外轮廓取凸包，沿现有简化精度找四个外侧顶点。顶点必须来自观测边界；不从三个 L 反算缺失 P1，不用矩形／仿射补出第四角。
5. 匹配结构为三个长臂 L 加一个短臂 M，四顶点由四个不同当前角片支撑。M 所在角是 P1；保持图像坐标下的正绕序，固定得到前一个 P0、后一个 P2、剩余 P3。图案内部 S 片不参与角精度估计，也不再通过模型投影搜索或绑定 S 片。
6. 截断、缺边导致不能形成完整四边形、身份不唯一或来源冲突时不产生该匹配。原质量残差／角误差／extension 高仍是标签，不作为匹配后丢弃四角的门。

上述局部归组有明确适用边界：多个贴近目标／L形强背景可造成组混合；不能将“唯一可识别匹配”宣传成通用任意多目标检测。需以负样本、双目标、边界截断、曝光变化和 MaixCam 实拍检查，不能只在本录像上放宽条件。

## 4. 四边形直接给边、固定身份与原图支持

对粗顶点 q[i]，直接以相邻顶点连线提供该角的两条邻边；沿现有物理角绕向约定选择顺序。没有“从外框再推变换、投影图纸邻边”的步骤。

原图轮廓每帧提取一次。每个 q[i] 从当前原图附近选择真实角片轮廓；两个角不得复用同一个角片作为完整角证据。保留连续、互不复用且有跨度的支持，两条线交点必须有限并位于原图内，不能把四边形跨白片间隙的长边当成整段实测连续像素。

最终输出为 CornerMeasurement 的四个 double 交点、来源、原始／模型残差、角误差、延伸量及质量标签。再按现有屏幕排序／发布契约输出 Detection，G2 仍使用 RAW。

## 5. 拟合方案与不新增门控的约束

优先比较普通 L2 与处理扫描奇偶偏移的现有周期模型，保留两条互补路线作为最小已知可行候选；支持提取、线求交、证据和标签只实现一份。其他模型仅作为实验对照，不能未经验证替换整个链路。

统计模型选择、稳健估计或支持搜索的变化必须有同样输入的对比依据；不能按帧号、设备名称或“让 frame 784 走回退”的目的写特殊分支，不能以较小 PnP RMSE 反向修改角点、强选平面解。若普通主路在新边提示下已经合法，必须如实记录回退触发变化；这个验收解释正在与用户核对。

质量标签不得变回拒绝：max_line_fit_error、max_corner_error 和 max_support_extension 继续只产生质量信息。数学不可求解、没有真实支持、来源冲突和出框不属于“低质量成功”。

参考原始资料只用于设计取舍：

- [AprilTag 2, Wang & Olson, 2016](https://april.eecs.umich.edu/media/media/media/pdfs/wang2016iros.pdf)：借鉴“先产生粗四边形，再从边界定位”的分工；不移植其完整黑白边框、编码或质量拒绝阈值。MARK 是离散 L/M 白片，需保持本节的连续支持来源。
- [OpenCV 4.x 形状与拟合接口](https://docs.opencv.org/4.13.0/d3/dc0/group__imgproc__shape.html)：普通 L2、稳健距离函数和轮廓原语供对照；使用仓库已有 OpenCV 4.6 可用接口，不为新 API 升级依赖。
- [Schwarz, 1978](https://www.andrew.cmu.edu/user/kk3n/simplicity/schwarzbic.pdf)：可比较带复杂度惩罚的模型选择，但连续轮廓像素相关、周期中位数并非高斯极大似然，不能套一个 BIC 公式便宣称更精确。是否采用取决于场景验证，非必选机制。

## 6. 验证与部署边界

1. 固定 b600635 的两条生产重投影预算、K/dist、输入视频和角点基线；保存原4360次候选拟合结果。既比较共同帧，也列出新增／失去的匹配，不能以少检难帧改善 RMSE。
2. 单独消融路线，再验证新的四边形输入，最后跑完整检测→位姿→跟踪→视频；记录 frame 784 的 P1 支持、结果和实际路线。
3. 录像无独立角点真值。角点位移只说明两版差异；绝对精度须由独立合成真值／可靠标注验证。PnP 保留 IPPE、多解与原 screening，不为演示改阈值；G4 保留 NIS、coast 和时间质量。
4. MaixCam 待验：实际分辨率／裁剪／镜头 K/dist、曝光与频闪、白色分割、ISP锐化／降噪、奇偶行残差、模糊、强反光／背景、透视角度、近远距离、边缘视场、像素支持跨度与定位预算、帧时间、运行耗时和内存。不得假定当前相机存在的周期效应会在 MaixCam 上相同出现。
5. 用 fx 比例提供像素预算迁移初值，原图坐标与单位不变；这只是缩放初值，不代替新传感器／镜头／ISP下重验。未知时间保持未知，0.5m/s规则值不直接变成视觉关联或速度拒绝门。
